# Publicar no GitHub / Publish on GitHub

## Português

1. Extraia o ZIP e abra a pasta `PitSignal`.
2. No GitHub, crie um repositório público, por exemplo `pitsignal`. Deixe desmarcada a criação automática de README, licença e .gitignore: estes arquivos já estão incluídos no pacote.
3. No repositório vazio, use o link para enviar arquivos existentes. Se ele já tiver arquivos, use **Add file > Upload files**.
4. Envie o conteúdo da pasta, incluindo `.gitignore` e `.gitattributes`. `README.md`, `painel_web.py` e os demais arquivos devem aparecer diretamente na raiz do repositório. Envie os arquivos extraídos, não somente o ZIP.
5. Confira a lista e confirme em **Commit changes**.

Este pacote foi preparado sem configurações pessoais, código de acesso, cache ou arquivos de execução. Ao enviar atualizações da sua pasta em uso, exclua esses arquivos também: o envio pelo navegador não usa o `.gitignore` como filtro.

O software é fornecido sem garantia. O componente `qrcodegen.py` tem seu próprio aviso MIT, mantido integralmente no arquivo.

### Para quem baixar

Baixe o repositório, extraia todos os arquivos e abra `INICIAR.bat` no Windows. Leia `README.pt-BR.md`. O programa continua executando no PC; o repositório distribui o código. O tablet usa o QR Code gerado pelo programa em execução na mesma rede.

## English

1. Extract the ZIP and open `PitSignal`.
2. Create a public GitHub repository, such as `pitsignal`. Do not generate a README, license or .gitignore automatically; these files are already included in the package.
3. In the empty repository, follow the link to upload existing files. For an existing repository, use **Add file > Upload files**.
4. Upload the extracted folder contents, including `.gitignore` and `.gitattributes`, directly to the repository root. Upload source files rather than only the ZIP.
5. Review the file list and select **Commit changes**.

This package excludes local preferences, access codes and runtime cache. Exclude them manually when uploading future updates through the website; browser uploads do not use `.gitignore` as a filter.

The project is distributed under the MIT License in `LICENSE`. It permits use, modification, redistribution and commercial use while preserving copyright and license notices. The software is provided without warranty. The separate MIT notice in `qrcodegen.py` remains intact.

People downloading the project should extract it and run `START.bat` on Windows. See `README.md`. The application runs on the user's PC; the repository distributes its source. The tablet connects through the QR code generated by the running application on the same network.
